# PivotHop social pack

Colors: paper `#f5f3ed` · ink `#15151a` · blue `#002FA6` (Klein ultramarine).
Four combos: `blue-on-paper` (the house look) · `ink-on-paper` · `paper-on-blue` · `paper-on-ink`.
(`blue-on-ink` is deliberately absent — 2.2:1 contrast fails.)

| File pattern | Size · ratio | Use it for |
|---|---|---|
| `pfp-1024-*.png` | 1024×1024 · 1:1 | Profile picture everywhere: LinkedIn (min 400²), X (400²), Instagram (min 320²). Mark only — sized to survive the circle crop. |
| `x-banner-1500x500-*.png` | 1500×500 · 3:1 | X profile header. Lockup sits clear of the avatar overlay (bottom-left). |
| `linkedin-banner-1584x396-*.png` | 1584×396 · 4:1 | LinkedIn personal profile banner. Lockup clear of the avatar overlay. |
| `linkedin-company-cover-1128x191-*.png` | 1128×191 · ~5.9:1 | LinkedIn company page cover (wordmark only — tagline unreadable at this height). |

Suggested pairings: paper banner + blue pfp (house), or blue banner + paper-on-blue pfp for a bolder page. Instagram has no banner — pfp only.
